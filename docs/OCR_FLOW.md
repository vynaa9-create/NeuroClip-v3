# NeuroClip V4 OCR Flow

```txt
Screenshot
-> OCR Watcher detect image
-> Tesseract read text
-> AI Cleaner normalize text
-> OCR notification ready
-> User choose Jawab / Balas / Salin
```

- Jawab: menjawab OCR secara langsung.
- Balas: membuka prompt manual dan memakai OCR sebagai konteks.
- Salin: menyalin teks OCR tanpa memicu Clip Watcher.
